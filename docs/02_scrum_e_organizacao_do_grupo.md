## 2. Organização de trabalho
**Duração da sprint:** `[Quinzenal]` *(6 sprints)*

**Ferramentas adotadas:**
- GitHub (Controle de versão e evidências)
- GitHub Projects (Gestão do fluxo de trabalho)
- Google Meet para as reuniões quinzenais
- WhatsApp para dúvidas e comunicação assíncrona

**Ritual de planejamento:**  
O planejamento será realizado via GitHub Projects. As tarefas serão organizadas utilizando *Issues* (separadas por funcionalidade), com *Labels* para indicar prioridades e equipes responsáveis, além de *Milestones* para agrupar as entregas de cada sprint.

**Ritual de acompanhamento:**  
O progresso será acompanhado pelo Scrum Master/PO e pela equipe por meio da movimentação dos cards no GitHub Projects e atualização constante do backlog.

**Ritual de revisão:**  
Ao fim de cada Sprint, será gerada uma entrega documentada no repositório (ex: `sprint-01.md`), contendo todos os artefatos linkados e o incremento validado pela equipe.

---

## 3. Definition of Done (DoD)
Um item será considerado concluído quando:
- estiver documentado;
- tiver sido revisado pelo grupo;
- atender aos critérios de aceitação;
- estiver versionado no GitHub;
- estiver alinhado com a sprint e com a entrega da disciplina.

---

## 4. Critérios de priorização do backlog
1. valor para o usuário;
2. urgência acadêmica;
3. dependências técnicas;
4. complexidade;
5. risco.

---

## 5. Convenções do repositório
- branch principal: `main`
- branches de trabalho: `feature/nome-curto` ou `bugfix/nome-curto`
- mensagens de commit: verbos no infinitivo ou imperativo
- PR com descrição objetiva
- registro de decisões importantes em arquivos da pasta `docs` (ex: `sprint-X.md` com evidências e prints de reuniões)

---

## 6. Exemplo de cerimônias
### Planejamento
- seleção dos itens prioritários via GitHub Projects;
- quebra em tarefas (Issues);
- uso de Labels e Milestones;
- definição de responsáveis.

### Revisão
- demonstração do que foi produzido;
- checagem do objetivo da sprint e atualização do arquivo da sprint atual;
- registro do que foi aceito.
